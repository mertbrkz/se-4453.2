# Basit Web Sitesi

Bu proje, GitHub'a yüklemek ve orada bir issue oluşturmak için kullanılan basit bir statik web sitesi örneğidir.

Klasör yapısı:

- `src/main/webapp/` — `index.html` ve `styles.css` içerir.

Hızlı başlama (yerel önizleme):

Windows üzerinde basitçe `index.html` dosyasını tarayıcıda açabilirsiniz veya bir static server kullanın:

```powershell
# Python 3 ile (bulunduğunuz dizini src/main/webapp yapın)
python -m http.server 8000
# sonra tarayıcıda http://localhost:8000 açın
```

Sonraki adımlar:

- Değişiklikleri commit'le ve GitHub'a pushla.
- GitHub üzerinde bir issue oluştur (örnek: "İlk deploy için hazırlık").
